# NSB Ruby — Arabic RTL Redesign

نسخة معاد تصميمها للموقع العربي، مبنية كواجهة ثابتة خفيفة ومهيأة للنشر المباشر على Vercel.

## الخصائص

- اتجاه RTL أصلي ومسار عربي `/ar/`.
- استخدام خط Alexandria في كامل الواجهة.
- لا توجد تبعيات npm أو مرحلة Build، مما يقلل مخاطر فشل النشر.
- تصميم متجاوب للجوال واللوحي وسطح المكتب.
- قائمة جوال قابلة للوصول ودعم لوحة المفاتيح.
- احترام `prefers-reduced-motion`.
- ترويسات أمان وتخزين مؤقت للأصول عبر `vercel.json`.
- صفحة 404 وملفا Sitemap وRobots.

## التشغيل محليًا

```bash
python -m http.server 4173
```

ثم افتح:

```text
http://localhost:4173/ar/
```

## النشر

اربط المستودع بمشروع Vercel، واجعل Root Directory هو جذر المستودع. لا يلزم أمر Build أو Output Directory.

## بيانات يجب تحديثها قبل النشر النهائي

- استبدال `hello@example.com` ببريد التواصل الرسمي.
- تحديث وصف الموقع وبيانات Open Graph بحسب نشاط NSB الفعلي.
- تحديث رابط Sitemap عند استخدام نطاق مخصص.
